# UC02 — Acessar Assistente Virtual

## Objetivo
Permitir que o estudante acesse o chatbot com Inteligência Artificial para receber auxílio durante a preparação para o ENADE.

## Ator principal
Estudante.

## Pré-condições
- O estudante deve estar autenticado.
- O estudante deve possuir permissão de acesso à plataforma.

## Fluxo principal
1. O estudante acessa a área do assistente virtual.
2. O sistema apresenta a interface do chatbot.
3. O estudante visualiza o campo para envio de mensagens.
4. O sistema disponibiliza a interação com o assistente.
5. O estudante pode enviar perguntas e receber respostas.

## Fluxos alternativos
- **A1 — Serviço de IA indisponível:** o sistema informa que o assistente está temporariamente indisponível.
- **A2 — Falha de comunicação:** o sistema informa que a mensagem não pôde ser processada.
- **A3 — Necessidade de atendimento especializado:** o estudante poderá seguir para o UC04 — Solicitar Atendimento Humano.

## Pós-condições
O estudante consegue acessar a interface do assistente virtual.

## Requisitos relacionados
RF04, RF05.
