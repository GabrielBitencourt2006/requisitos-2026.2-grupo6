# Registro dos Resultados das Entrevistas ( em produção ) 

## 1. Objetivo

Este documento será utilizado para registrar e consolidar as informações coletadas nas entrevistas realizadas com estudantes, professores e representantes da coordenação acadêmica.

## 2. Situação da coleta

**Status:** aguardando preenchimento após a realização das entrevistas.

Os resultados abaixo não representam respostas reais. Este documento é um modelo de registro para a etapa de elicitação.
